# Project Diagrams

This folder contains the main technical diagrams used to document the architecture, firmware logic, and hardware implementation of the Smart Posture T-Shirt.

## Contents

### 1. System Architecture

**File:** `system-architecture.png`

Illustrates the overall system architecture, showing the flow of data and control between the MPU6050 IMU sensor, ESP32 microcontroller, vibration motors, and power source.

### 2. Firmware Flowchart

**File:** `firmware-flowchart.png`

Illustrates the firmware logic of the posture correction system, including system initialization, IMU calibration, posture detection, and activation of vibration feedback when slouching is detected.

### 3. Posture Monitoring Block Diagram

**File:** `posture-monitoring-block-diagram.png`

Shows the hardware-level connections between the MPU6050 sensor, ESP32 microcontroller, transistor motor driver circuit, vibration motors, and USB power bank.

## Purpose

These diagrams provide a visual representation of the Smart Posture T-Shirt's system architecture and operation, complementing the source code and prototype documentation included in this repository.
